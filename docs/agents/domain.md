# Domain docs

LineWise has one domain context. [CONTEXT](../../CONTEXT.md) defines vocabulary; [PRD v2.0](../linewise_prd_v2_0.md) defines requirements and explicitly retained v1.1 sections; the [UI spec](../linewise_ui_spec_v1.md) defines presentation and interaction.

Use [ADRs](../adr/README.md) for durable product or architecture decisions. [Roadmap](../roadmap.md) defines execution order; [current audit](../linewise_status_2026-10-05.md) records implementation evidence. Archived and research documents provide context, not active requirements.
