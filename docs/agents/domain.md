# Domain Docs

Climb is a single-context project.

- Read `CONTEXT.md` before product, architecture, bug, or test work.
- Use `docs/adr/` for durable decisions that change product scope, sensor claims, data model, Apple platform contracts, or release gates.
- Treat the latest PRD as the implementation contract once it exists.
- Until a PRD exists, treat `docs/bouldering_field_research_v2.md`, `CONTEXT.md`, and ADRs as the requirements source.
- Historical exploration docs in `docs/` are useful context, but they do not override `CONTEXT.md`, the active PRD, or ADRs.
