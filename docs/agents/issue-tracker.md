# Issue Tracker

This project uses GitHub Issues in the public `WILLOSCAR/linewise` repository.

- Create product and implementation work as GitHub Issues after the P0 PRD and validation gates are settled.
- Prefer one issue per independently verifiable slice.
- Link each issue back to `CONTEXT.md`, the relevant PRD, or an ADR when the decision is product-sensitive.
- Use the GitHub triage labels documented in `docs/agents/triage-labels.md`.
- Do not create implementation issues before the P0 PRD and validation gates are settled.
- External PRs are not currently treated as a request surface.
