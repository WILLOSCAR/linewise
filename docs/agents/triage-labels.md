# Triage Labels

Use these workflow states for GitHub Issues in `WILLOSCAR/linewise`:

| Role | Status |
| --- | --- |
| Maintainer needs to evaluate | `needs-triage` |
| Waiting on user or field evidence | `needs-info` |
| Ready for an agent | `ready-for-agent` |
| Ready for a human | `ready-for-human` |
| Will not be actioned | `wontfix` |

Topic labels such as `product`, `watch`, `iphone`, `healthkit`, `motion`, `ui`, `validation`, and `research` may be used when helpful.
