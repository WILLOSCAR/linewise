## 0. Executive Summary

### 0.1 最核心判断

抱石在中国的增长，不只是“年轻人又多了一个运动爱好”，而是一条由三层结构共同推动的产业线：

1. **历史层**：现代攀岩通过国外运动攀登文化、国家队竞赛体系和阳朔等自然岩场进入中国；阳朔把中国自然岩壁从“好岩壁”变成了“可旅游、可路书、可向导、可节庆的目的地”。
2. **城市层**：室内岩馆把野外攀岩的风险、距离和门槛转译成城市里可重复消费的运动体验；抱石因为不需要绳索保护、社交和打卡属性强，最适合在北京、上海这类高密度城市里扩张。
3. **商业层**：真正赚钱的不只是门票，而是 `体验票 -> 会员/次卡 -> 私教/团课 -> 青少儿长期课 -> 赛事/营地/团建 -> 装备零售/品牌合作/内容传播` 的复合模型。

一句话总结：

> 抱石馆不是单纯的运动场地，而是把“攀岩动作内容、城市社交空间、青少儿体育教育、低门槛打卡体验、品牌线下触点”组合在一起的复合生意。

## 1. 抱石到底是什么生意？

抱石表面上是室内攀岩的一种形式：墙高较低，不使用绳索，地面铺厚垫，用户通过短时间、高强度、多次尝试完成不同难度线路。

但商业上，抱石不是“体育场馆按小时出租”的简单模型。它更像下面几个业务的叠加：

| 业务本质 | 在岩馆里的表现 | 商业意义 |
| --- | --- | --- |
| 运动健身 | 全身力量、核心、灵活性、协调性训练 | 替代传统健身房，对非健身人群更有趣。 |
| 解题游戏 | 读线、试错、改动作、终于完成一条线 | 形成即时反馈和上瘾机制。 |
| 城市社交 | 一个人也能去，现场自然讨论 beta | 比跑步/健身房更容易产生陌生人互动。 |
| 内容打卡 | 岩壁、动作、掉落、成功瞬间天然适合短视频/小红书 | 拉新成本下降，品牌传播更强。 |
| 青少儿体育教育 | 体能、专注力、胆量、赛事、等级和训练体系 | 高复购、高家长付费意愿，是稳定现金流。 |
| 轻竞技 | 赛事、挑战赛、馆内排行榜、城市赛 | 提高留存和社群身份。 |
| 生活方式空间 | 咖啡、零售、活动、品牌联名、周末社交 | 提高停留时长和非门票收入。 |

这也是为什么抱石比绳索攀岩更容易城市化。它不需要每个新手先学复杂保护技术，不强依赖固定保护搭子，可以一个人下班去，也可以两三个人一起社交，天然适合北京、上海这类高密度城市。

## 2. 历史纵轴：从野外岩壁到城市岩馆

### 2.1 中国攀岩有三条起源线

中国攀岩不是一条线长出来的，而是三条线叠加：

| 时间线 | 核心起点 | 代表意义 |
| --- | --- | --- |
| 国家竞赛线 | 1980s 后期，中国登山协会派员学习，1987 年怀柔大水峪赛事常被视为中国攀岩元年 | 形成国家队、赛事、裁判、教练、标准化训练体系。 |
| 自然岩壁线 | 1990 年前后，Todd Skinner 等国外攀岩者在阳朔月亮山开线 | 把中国带入现代 sport climbing / route development 语境。 |
| 室内商业线 | 2010s-2020s，岩馆大量出现，东京/巴黎奥运进一步破圈 | 把攀岩从小圈层爱好推向城市消费、青训和大众运动。 |

### 2.2 野攀是不是从国外传来的？

如果说的是现代运动攀登意义上的 `sport climbing`、固定保护点、路线难度、路书、首攀伦理、岩场开发、商业向导服务，那么答案基本是：

> 是的，中国现代野外攀登很大程度受国外攀岩文化和国际攀岩者影响，阳朔就是典型样本。

但这句话需要加两个限定：

1. **中国并非没有本土悬崖文化**。例如贵州格凸河一带本来就有“蜘蛛人”式的悬崖劳作传统，只是那不是现代 sport climbing 的训练、保护和路线体系。
2. **中国现代攀岩也有国家体育体系来源**。1987 年前后的国家队/竞赛线，和阳朔的自然岩壁线是并行发生的，不应该混成一条故事。

### 2.3 阳朔为什么重要？

阳朔重要，不只是因为那里有好岩壁，而是因为它最早把岩壁变成了一个完整目的地：

| 要素 | 阳朔为什么具备 |
| --- | --- |
| 岩壁资源 | 喀斯特石灰岩地貌，路线密集，风格多样。 |
| 旅游基础设施 | 西街、住宿、餐饮、交通、背包客文化成熟。 |
| 国际社群 | 早期欧美攀岩者和后来常驻岩友持续开发线路。 |
| 路书和知识 | Paul Collis、Andrew Hedesh 等路书把路线知识系统编码。 |
| 商业向导 | 体验课、商业指导、装备租赁和攀岩俱乐部逐渐形成。 |
| 节庆传播 | 阳朔攀岩节让本地岩场有了品牌传播和社群聚合。 |

可引用的稳妥说法是：

> 早 90 年代，Todd Skinner 在阳朔月亮山完成关键开线，开启了中国现代自然岩壁运动攀登的象征性阶段。关于具体年份，公开资料在 1990 和 1992 之间有差异，正式表述宜使用“早 90 年代”。

### 2.4 从阳朔到室内岩馆

阳朔、黎明、格凸、石鼓等自然岩场解决的是“深度攀岩者”的身份认同、旅行和技术进阶；室内岩馆解决的是“城市大众”的参与门槛。

两者不是替代关系：

| 场景 | 解决什么 | 商业化方式 |
| --- | --- | --- |
| 自然岩场 | 旅行、冒险、路线伦理、装备升级、身份认同 | 向导、路书、营地、节庆、文旅、品牌线路开发。 |
| 室内岩馆 | 高频训练、安全感、青训、社交、赛事、复购 | 门票、会员、私教/团课、青训、团建、零售、活动。 |

中国目前最缺的不是“更多人体验一次攀岩”，而是从 `gym climbing` 过渡到 `outdoor judgment` 的教育层：如何判断岩壁、保护点、落点、天气、路线伦理、access 和本地社区关系。

## 3. 中国岩馆行业现状

### 3.1 市场规模和增长

公开行业报告摘要显示，截至 2025 年 1 月，中国国内攀岩场馆达到 811 家，同比增长 27.5%，覆盖 159 座城市，上海、北京、深圳继续位列岩馆数量前三。巴黎奥运会后，攀岩相关声量和互动量也有显著增长。

这意味着行业已从非常早期的小众状态，进入“需求增长但经营开始分化”的阶段。

### 3.2 主要增长动力

| 增长动力 | 具体表现 | 深层含义 |
| --- | --- | --- |
| 奥运破圈 | 东京奥运后项目大众化，巴黎奥运中国速度项目银牌继续放大关注 | 奥运带来新客教育，但不保证长期留存。 |
| 商场化 | 大量岩馆进入商场、办公园区、城市更新空间 | 攀岩被包装成城市休闲消费，而不是传统体育训练。 |
| 青少儿培训 | 超九成岩馆关注青少年，赛事和青训体系增长 | 岩馆越来越像体育教育机构。 |
| 女性用户增长 | 女性活动、女性夜、社媒内容明显增加 | 抱石从硬核圈层转向安全、社交、塑形和表达。 |
| 内容平台传播 | 微信、小红书、抖音成为获客基础设施 | 岩馆经营必须懂内容、私域和社群。 |
| 赛事体系 | 中国攀岩联赛、青少年赛事、城市赛事增多 | 赛事把“玩一次”变成“可持续训练路径”。 |

### 3.3 行业已进入分化阶段

未来不是所有岩馆都会同样受益。更可能出现几类分化：

| 馆型 | 优势 | 风险 |
| --- | --- | --- |
| 商场标准化连锁馆 | 流量强、品牌统一、适合新手和白领 | 租金高、同质化、平台促销压毛利。 |
| 社区精品抱石馆 | 社群强、技术氛围好、复购高 | 获客半径有限，老板/定线/教练依赖重。 |
| 青少儿培训馆 | 课包稳定、家长付费意愿高 | 安全责任重，课程体系和教练质量要求高。 |
| 综合大型岩馆 | 项目全、赛事和训练能力强 | 初始投入大，运营复杂，回本周期长。 |
| 高端会员制俱乐部 | 客单价高、服务深、品牌调性强 | 目标用户窄，复制难，对团队要求极高。 |

## 4. 北京市场：商场化、青训化和多极竞争

### 4.1 北京市场画像

北京已经是全国头部攀岩城市之一。它的用户结构大致可以分成四类：

| 用户 | 需求 | 典型场景 |
| --- | --- | --- |
| 下班白领 | 解压、社交、运动替代、成就感 | 工作日晚高峰、办公区附近岩馆。 |
| 高校/年轻人 | 新鲜体验、打卡、社交、低门槛运动 | 高校和创意园区周边。 |
| 亲子/青少年 | 体能、胆量、专注力、赛事、长期课 | 周末、寒暑假、青训班。 |
| 进阶岩友 | 定线质量、训练氛围、活动、装备 | 精品馆、社区馆、技术工作坊。 |

北京市场的关键词是：

> 商场化 + 连锁化 + 青训化 + 大馆化 + 高端俱乐部分化。

### 4.2 北京代表品牌与门店

| 品牌/样本 | 定位 | 价格与产品特征 | 判断 |
| --- | --- | --- | --- |
| 香蕉攀岩 Shangdi / 768 | 全国连锁、标准化、偏白领/家庭/高校 | 官网标准价单次 120 元，月卡 599 元，成人体验课和青少年课体系清晰 | 品牌感和标准化最强，但北京不是其门店最密城市。 |
| 奥攀攀岩 | 北京本地多点布局，偏亲子/青训/社区 | 多校区，公开招聘和介绍中强调 4-14 岁、青训、课程研发 | 北京青少儿体育教育化的代表。 |
| 岩时攀岩 | 社区型/综合型，抱石+顶绳 | 新手课、会员训练营、顶绳技能门槛 | 适合从抱石过渡到更综合攀岩。 |
| ClimbOn / COG | 商圈更新场景，偏年轻白领 | 商场和首钢园等城市更新空间 | 更像城市运动社交场。 |
| CAMP4 / Mellow | 中心城区 boutique / 社区精品 | 单次、月卡、挑战赛、技术工作坊 | 通过氛围、活动和定线维持粘性。 |
| 我攀 | 高端会员制/旗舰馆 | 年费高、全教练制、赛事/社群/硬件输出 | 不是大众馆打法，更像高端俱乐部和行业赋能样本。 |

### 4.3 北京的深层特点

北京比上海更容易看到“体育教育化”的一面：

1. 家庭对青少儿体能、专注力、赛事路径有长期投入意愿。
2. 青训馆、夏令营、比赛、校区合作更容易形成长期现金流。
3. 高端会员制和精品社区馆也能存在，因为高收入、高学历、高频运动用户足够多。
4. 但北京的通勤距离和城市尺度也会影响复购，用户常常不是“不喜欢”，而是“太远、太忙、太麻烦”。

## 5. 上海市场：场景消费、白领社交和高密度竞争

### 5.1 上海市场画像

上海攀岩馆已经从小众专业运动场，进入大众运动消费和社交生活方式阶段。公开报道中可见的演进线是：

| 阶段 | 公开口径 | 含义 |
| --- | --- | --- |
| 2014 年 | 上海约 5 家攀岩馆 | 仍是小众专业运动。 |
| 2021 年 | 增至 65 家 | 奥运化、商场化后开始持续增长。 |
| 2024 年 | “近百家”遍布 16 区 | 已经进入大众消费视野。 |
| 2025 年初 | 行业报告摘要称上海 103 家 | 上海为全国岩馆数量第一梯队。 |
| 2026 年 | 部分媒体口径称经营性攀岩馆已达 121 家 | 市场密度非常高，竞争进入运营质量阶段。 |

上海关键词是：

> 商场化 + 滨江/办公综合体 + 年轻白领 + 女性友好 + 社交打卡 + 场景溢价。

### 5.2 上海代表品牌与门店

| 品牌 | 样本 | 定位 | 判断 |
| --- | --- | --- | --- |
| 香蕉攀岩 | 嘉里合集 BANANA+、延安西路、金虹桥 | 全国连锁、核心商圈、标准价盘、月度换线、私域运营 | 标准化和数字化程度较高，适合白领、情侣/朋友初体验和青少年续费。 |
| 岩时攀岩 | 西岸梦中心等 | 城市地标型综合岩馆，绑定江景、筒仓、滨江消费 | 卖的不只是上墙，也卖场景、建筑空间和停留体验。 |
| Vmore / Vfour | 北外滩、浦东等 | 都市白领/年轻人导向的抱石社交产品 | 代表轻量化、商场/办公综合体嵌入式抱石馆。 |
| Climbing Factory | 宝山大场馆 | 抱石、顶绳、先锋、速度、学校/户外探险业务 | 更偏训练/综合/学校合作，不是纯商场社交馆。 |

### 5.3 上海的深层特点

上海岩馆更像“城市生活方式空间”：

1. 商场、滨江、办公综合体把岩馆变成可被围观、可打卡、可顺路消费的场景。
2. 白领和年轻用户把抱石当成下班后的社交运动，而不是纯训练。
3. 女性友好活动、品牌联名、社交媒体内容更容易发酵。
4. 市场密度高之后，拼低价不是长期答案，拼的是选址、空间体验、路线更新、社群运营和课程转化。

## 6. 香蕉攀岩案例：商场里的攀岩生活方式连锁

### 6.1 基本画像

香蕉攀岩目前已经不是单点岩馆，而是全国化连锁品牌。官网显示其为 `23+` 馆、覆盖 `8` 城，价格、课程、门店、活动都有统一呈现。公开资料中，工商主体与品牌起点存在两个口径：工商主体北京猎动教育科技有限公司成立于 2015 年，品牌官方口径为 2019 年创立。这个差异在正式材料中应区分表述。

### 6.2 香蕉的打法

| 模块 | 做法 | 商业意义 |
| --- | --- | --- |
| 选址 | 核心商圈、商场、办公区、年轻人密集区域 | 用自然流量和可见空间降低获客成本。 |
| 定价 | 单次 120 元、10 次 950 元、月卡 599 元、年卡 4799 元等标准价盘 | 降低用户理解成本，有利于跨店复制。 |
| 体验课 | 成人体验课、双人体验课、青少年团课和私教 | 体验课承担拉新和转化功能。 |
| 私域 | 企业微信、会员标签、期限卡转化、公开课/团课 | 把平台流量变成可运营会员资产。 |
| 社群 | 女性赛事、开业赛、抱石马拉松、品牌联名 | 让用户有再次到店和发内容的理由。 |
| 复合业态 | 装备零售、咖啡、鞋履维保、活动、团建 | 扩大非门票收入和停留时长。 |
| 标准化 | 价格、门店、课程、私域、招聘、运营流程逐渐统一 | 是从 20+ 店继续扩张的基础。 |

### 6.3 香蕉的优势

1. **品牌化强**：它卖的是低门槛、好看、好玩、可社交的城市抱石，而不是硬核极限运动。
2. **选址强**：商场/办公区让攀岩变成“下班顺路”和“周末消费”。
3. **价格清晰**：官网价盘完整，用户不用先问销售。
4. **活动能力强**：女性 IP、抱石赛、联名活动让内容传播自然发生。
5. **私域意识强**：不是只靠点评/美团成交，而是把用户沉淀到会员和课程体系。

### 6.4 香蕉的风险

| 风险 | 解释 |
| --- | --- |
| 高租金 | 商场带来流量，也带来租金和商圈表现依赖。 |
| 高换线成本 | 线路是核心内容，持续换线需要专业定线和岩点投入。 |
| 标准化难 | 教练、定线、安全、社群氛围很难像咖啡一样完全复制。 |
| 安全责任 | 攀岩属于高风险运动，任何事故都会影响品牌信任。 |
| 平台促销压毛利 | 团购和渠道价能拉新，也可能降低单客毛利。 |
| 竞争升温 | 北京上海已有大量本地馆、精品馆和综合馆，用户选择越来越多。 |

## 7. 盈利点：岩馆具体怎么赚钱？

### 7.1 收入结构

| 收入来源 | 典型形式 | 稳定性 | 毛利/战略意义 |
| --- | --- | --- | --- |
| 单次票/体验票 | 单次入场、新人体验、双人体验 | 中 | 拉新入口，利润不是唯一目的。 |
| 次卡/月卡/年卡 | 10 次卡、20 次卡、月卡、季卡、年卡 | 高 | 基础现金流，决定日常经营稳定性。 |
| 私教 | 成人入门、技术纠错、进阶突破、带绳安全 | 高 | 高客单、高信任、强转化。 |
| 团课 | 青少年团课、成人公开课、技巧课 | 高 | 可标准化、可复制，适合规模化。 |
| 青少儿长期班 | 启蒙、进阶、竞训、夏令营、赛事集训 | 很高 | 最稳定 LTV，是很多馆的核心收入池。 |
| 企业团建 | 包场、公司活动、体验课组合 | 中 | 消化工作日空档，高客单但复购不稳。 |
| 赛事活动 | 开业赛、抱石赛、馆际赛、女性夜 | 中 | 增强社群和传播，不一定直接高利润。 |
| 装备零售/租赁 | 鞋、镁粉、粉袋、护具、服饰 | 中 | 攀岩鞋强依赖试穿，线下有优势。 |
| 咖啡/轻餐/酒 | 咖啡、简餐、精酿、休息区消费 | 低-中 | 提高停留时长，头部复合空间可做第二曲线。 |
| 品牌合作 | 联名路线、试鞋会、赛事赞助、内容共创 | 中 | 更适合头部馆和有内容能力的馆。 |
| 户外活动 | 阳朔/自然岩壁体验、野攀教学、旅行 | 中 | 帮用户从室内进阶到户外，客单高但组织风险高。 |

### 7.2 收入漏斗

岩馆最常见的商业漏斗是：

```text
社媒/商场/朋友带来
  -> 体验票 / 新人课
  -> 月卡 / 次卡
  -> 私教 / 团课
  -> 青少儿长期班 / 成人进阶课
  -> 赛事 / 训练营 / 野攀 / 装备
  -> 长期社群与品牌认同
```

其中最关键的不是用户第一次来，而是：

1. 第一次是否感到安全；
2. 是否完成了一条线并获得成就感；
3. 是否有人教他/她怎么继续进步；
4. 是否有朋友、社群或课程让他/她下次再来；
5. 是否能看到自己的进步路径。

### 7.3 成本结构

| 成本 | 说明 | 为什么重要 |
| --- | --- | --- |
| 租金 | 商场、办公区、滨江空间租金差异很大 | 决定单店盈利压力。 |
| 装修/岩壁 | 岩壁、钢结构、垫子、空间设计、消防 | 初始投入高，回本周期通常不短。 |
| 岩点和换线 | 岩点采购、定线员、线路重置 | 路线是岩馆的内容库存。 |
| 人力 | 教练、前台、运营、店长、定线、安全巡场 | 教练质量直接影响留存和转化。 |
| 设备维护 | 自动保护器、绳索、安全带、垫子、消防 | 安全底线和合规基础。 |
| 获客 | 美团/点评、小红书、抖音、微信私域、活动 | 新手持续进入是现金流基础。 |
| 保险与合规 | 高危险性体育项目许可、人员资质、公众责任等 | 出事故会直接伤害经营。 |

### 7.4 一个重要认知：路线就是内容

岩馆真正持续生产的不是“墙”，而是“路线”。墙是基础设施，路线才是内容。

这和内容产品很像：

| 内容产品 | 岩馆 |
| --- | --- |
| 视频/文章 | 一条抱石线路 |
| 编辑/创作者 | 定线员 |
| 用户反馈 | send 率、排队、吐槽、复爬 |
| 内容更新 | 换线 |
| 用户留存 | 下次来试新线 |

因此，优秀岩馆的运营能力不只是“建一个漂亮场地”，而是持续生产难度合理、风格多样、有讨论度、能让不同水平用户都有成就感的路线。

## 8. 教练模式：不是纯老师，而是复合经营岗位

### 8.1 教练在岩馆里的真实角色

北京和上海公开招聘样本显示，岩馆教练常常同时承担：

1. 新手教学；
2. 安全讲解和巡场；
3. 体验课转化；
4. 会员维护；
5. 私教和团课交付；
6. 青少儿课程和家长沟通；
7. 活动执行；
8. 有些情况下还参与基础定线或线路维护。

所以，教练不是传统意义上的“只上课”，而是：

> 安全体验负责人 + 课程交付者 + 销售转化节点 + 会员留存节点 + 社群氛围制造者。

### 8.2 课程体系

| 课程类型 | 用户 | 价值 |
| --- | --- | --- |
| 新手体验课 | 第一次来的成人/情侣/朋友 | 降低恐惧，完成第一条线，促成办卡。 |
| 成人私教 | 入门纠错、进阶瓶颈用户 | 高客单、高信任，解决技术问题。 |
| 成人公开课 | 有月卡但缺目标的用户 | 提高到店频次和社群关系。 |
| 青少儿团课 | 6 岁以上儿童 | 规模化交付，稳定课包收入。 |
| 青少儿私教 | 有明确提升/比赛目标的家庭 | 高客单，家长期望强。 |
| 竞训队/俱乐部 | 有赛事路径的青少年 | 建立长期成长路径和品牌壁垒。 |
| 营地/集训 | 寒暑假、节假日 | 提高淡旺季利用率和客单价。 |

### 8.3 教练资格与监管

攀岩在中国属于高危险性体育项目，经营主体需要符合相关标准与许可要求。教练/指导员体系大致有两条：

| 体系 | 作用 |
| --- | --- |
| 攀岩社会体育指导员 | 关联高危险性体育项目上岗和场馆许可，是合规底线。 |
| 中国登山协会攀岩教练员等级体系 | 更偏训练、竞赛、青训和教练能力分层。 |

这意味着未来岩馆的竞争会越来越依赖“合规、教练质量、课程体系和安全管理”，而不是单纯靠装修和流量。

### 8.4 教练收入逻辑

公开招聘样本显示，教练收入常见结构是：

```text
固定底薪 + 课时费 / 绩效奖金 + 销售或续费提成 + 活动/赛事/带队收入
```

收入天花板高的教练通常具备：

1. 会教新手，能让用户不害怕；
2. 能做销售转化，但不让用户反感；
3. 能带青少儿长期班；
4. 能带比赛或训练营；
5. 有定线/训练/康复/体能等复合能力；
6. 能经营社群和个人口碑。

## 9. 用户生命周期：为什么入坑、为什么留下、为什么离开

### 9.1 入坑

抱石的入坑路径很清晰：

| 入坑触发 | 解释 |
| --- | --- |
| 朋友带去 | 降低陌生感，第一次有人陪。 |
| 小红书/抖音打卡 | 动作和空间视觉冲击强，容易被种草。 |
| 下班解压 | 比健身房更有趣，比酒局更健康。 |
| 低装备门槛 | 租鞋+镁粉即可开始。 |
| 第一次完成线路 | “我原来可以做到”带来强成就感。 |
| 社交氛围 | 一个也能去，但现场不孤独。 |

### 9.2 留存

用户留下来，通常不是因为“运动消耗大”，而是因为：

1. **解题感**：每条线都是一个身体谜题。
2. **可见进步**：从 V0/V1 到更高难度，进步直观。
3. **社群支持**：别人给 beta、鼓励、一起 project。
4. **心流和减压**：爬的时候很难想工作烦心事。
5. **身份认同**：逐渐从“我试过攀岩”变成“我是岩友”。

### 9.3 退坑

用户离开，通常不是因为“不好玩”，而是：

| 退坑原因 | 解释 | 岩馆可怎么缓解 |
| --- | --- | --- |
| 伤病 | 手指、脚踝、膝盖、肩肘腕，或摔落心理阴影 | 教落地、热身、恢复课、伤后回归方案。 |
| 太远 | 通勤成本高，复购下降 | 多店通用、社区店、下班时段产品。 |
| 太贵 | 月卡/私教/装备成本叠加 | 新人月卡、阶梯价格、次卡组合。 |
| 平台期 | 只追 grade 后挫败感强 | 技术主题课、project 日志、弱项训练。 |
| 没人一起 | 社交网络断裂后动力下降 | 固定活动夜、女性夜、新手局、搭子群。 |
| 恐惧 | 怕高、怕摔、见过事故 | 安全教育、低风险线路、教练陪伴。 |

### 9.4 对产品的启发

用户真正想保留的不是单次运动数据，而是：

1. 我今天尝试了什么；
2. 哪条线终于完成了；
3. 哪条线卡住了；
4. 我休息够不够；
5. 我为什么失败；
6. 下次去应该先试什么；
7. 我是不是在进步。

这也解释了为什么普通运动记录 App 对抱石不够：它们记录了时长、心率、卡路里，但没有记录 `attempt / rest / send / fail / project / beta / fear / confidence`。

## 10. 赛事、品牌和内容平台

### 10.1 赛事让攀岩变成可商业化体育 IP

国家体育总局和中国登山协会公开赛事申办材料中，已经把中国攀岩联赛定位为推动攀岩赛事朝标准化、商业化、市场化、职业化方向发展的平台。“一带一路”国际攀岩大师赛也强调主题性、地域性和观赏性。

赛事对岩馆的意义不只是比赛当天收入，而是：

1. 给青少儿训练一个目标；
2. 给教练能力一个展示场；
3. 给家长付费一个理由；
4. 给品牌合作一个场景；
5. 给社群一个共同记忆；
6. 给城市和商圈一个活动 IP。

### 10.2 品牌从卖装备转向抢场景

户外品牌和装备品牌正在从“卖鞋、卖绳、卖装备”转向“进入攀岩场景”：

| 品牌动作 | 对岩馆的意义 |
| --- | --- |
| 试鞋会 / 试穿会 | 攀岩鞋强依赖线下试穿，岩馆天然是渠道。 |
| 联名线路 | 品牌变成路线内容的一部分。 |
| 赛事赞助 | 提供物料、奖金、传播和用户触点。 |
| 工作坊 | 教练、运动员、装备专家成为内容源。 |
| 社群夜 | 品牌不只曝光，而是嵌入用户关系。 |

### 10.3 内容平台是经营基础设施

微信、小红书、抖音、大众点评/美团都在岩馆获客中扮演角色，但分工不同：

| 平台 | 作用 |
| --- | --- |
| 微信/企业微信 | 私域、会员维护、活动通知、课程续费。 |
| 小红书 | 种草、女性用户、装备体验、第一次抱石记录。 |
| 抖音 | 破圈传播、挑战视频、赛事/高难动作曝光。 |
| 大众点评/美团 | 新客转化、价格促销、门店评价。 |
| B 站/YouTube | 技术讲解、训练复盘、品牌纪录片。 |

深层结论：

> 今天的岩馆经营不只是线下运营，而是“线下体验 + 线上内容 + 私域复购”的一体化系统。

## 11. 国际对照

### 11.1 欧美成熟馆

欧美头部馆已经把岩馆做成“生活方式基础设施”：

| 样本 | 特点 |
| --- | --- |
| Movement | 多店会员、瑜伽、fitness、gear shop、co-working、青少年项目。 |
| The Climbing Hangar | 咖啡、社群活动、women session、无合约会员、免费课等权益。 |
| Arkose | 餐厅和攀岩结合更深，餐饮不是简单配套，而是独立吸引物。 |
| Climbing District | 把 social club、guest pass、coached class 包进会员权益。 |

与北京/上海相比，欧美成熟馆更强在：

1. 会员权益打包；
2. 社群制度化；
3. 餐饮/办公/健身等复合空间；
4. 成人进阶课程产品化；
5. 定线透明度和 setter 培养。

### 11.2 日韩样本

日本、韩国更值得关注的是：

1. 高密度都市连锁；
2. 标准化课程；
3. App 中台；
4. 路线记录和 setting schedule；
5. 可复制店型。

这对中国岩馆的启发是：未来不是每家店都要做一个完整 App，但岩馆运营一定会越来越依赖数字化系统，包括会员、签到、课表、路线、活动、通知、训练记录和社群。

## 12. 未来 3-5 年趋势判断

### 12.1 增长会继续，但逻辑变化

未来 3-5 年，行业增长会从“奥运破圈带来的新客红利”，转向“留存、复购、课程、社群和数据化运营”的结构性竞争。

| 趋势 | 判断 |
| --- | --- |
| 抱石优先 | 抱石比绳攀更适合城市商场、社交、打卡和新手体验。 |
| 青少儿核心化 | 青训、赛事、营地和家长服务将是最稳定现金流。 |
| 女性主流化 | 女性不是边缘增量，而是主流用户，需要安全感、社交感和表达空间。 |
| 连锁区域化 | 会出现更多区域龙头和跨城品牌，但不一定像健身房一样全国平推。 |
| 内容运营常态化 | 路线更新、挑战赛、教练人设、用户故事都将内容化。 |
| 数据化增强 | 排课、CRM、训练记录、家长报告、路线热度、会员留存会成为后台能力。 |
| 合规分水岭 | 安全、教练资质、设备维护和保险会越来越重要。 |
| 复合空间升级 | 咖啡、零售、艺术展、精酿、办公和品牌活动会进入头部馆。 |

### 12.2 最高确定性的机会

| 机会 | 为什么确定 |
| --- | --- |
| 青少儿课程体系 | 长期 LTV 高，家长付费明确，赛事路径清晰。 |
| 区域连锁运营系统 | 多店复制需要 SOP、教练、定线、CRM 和私域能力。 |
| 女性友好社群 | 用户增长和内容传播都强。 |
| 教练 OS / 岩馆 SaaS | 排课、课包、家长反馈、训练档案、赛事报名都需要系统化。 |
| 训练记录与复盘 | 对成人进阶用户和 Watch 用户有潜在价值。 |
| 训练板和硬件软件化 | LED 板、指力板、计时器、训练计划可形成数据闭环。 |

### 12.3 高风险机会

| 机会 | 风险 |
| --- | --- |
| 纯 C 端社交 App | 没有岩馆和教练网络，冷启动困难。 |
| 全国性重资产快速开馆 | 租金、人才、安全和标准化压力极高。 |
| 只靠 AI 动作识别 | 数据难、误判多、场景复杂，用户未必愿意持续记录。 |
| 只做打卡社区 | 打卡拉新强，但长期留存弱。 |
| 户外安全承诺 | 法律和实际安全风险过高。 |

## 13. 对个人理解和创业/产品机会的启发

### 13.1 如果你只是想更懂这项运动

可以按下面路径理解：

1. **先从室内抱石入门**：体验不同馆、不同定线风格、不同人群。
2. **观察商业细节**：价格、课包、教练话术、会员活动、换线节奏、私域运营。
3. **理解历史根系**：了解阳朔、月亮山、路书、野攀伦理、户外 access。
4. **体验不同城市馆**：北京偏青训/社区/高端分化，上海偏场景/社交/生活方式。
5. **记录自己的训练**：attempt、send/fail、休息、主观疲劳、恐惧、动作卡点。
6. **再看户外转化**：从岩馆到自然岩壁，中间需要安全、装备、判断和伦理教育。

### 13.2 如果你想从 Watch App 切入

不要先做“攀岩版 Strava”，也不要先做“全自动动作识别”。更合理的切口是：

> 面向室内抱石用户，用 Apple Watch 低干扰记录训练锚点，用 iPhone 整理 project 记忆和下次训练提示。

为什么这个切口成立：

| 行业洞察 | 产品机会 |
| --- | --- |
| 抱石是多次尝试和休息组成的运动 | Watch 适合记录 rest timer、attempt 和低干扰标记。 |
| 用户留存靠可见进步 | iPhone 可做 project history、send rate、失败原因和下次提示。 |
| 普通运动数据不够攀岩化 | 需要 attempt/rest/send/fail/project 语义层。 |
| 岩馆和教练需要用户长期记录 | 后续可扩展成教练反馈、家长报告或训练档案。 |
| 自动识别容易误判 | P0 应 manual-first，自动结果只做 suggested timeline。 |

### 13.3 你去攀岩时可以顺手收集的数据

| 数据 | 记录方式 | 为什么有价值 |
| --- | --- | --- |
| 训练总时长 | Watch / 手动 | 基础训练量。 |
| 每条线 attempt 次数 | Watch 一键或训练后补 | 抱石最核心事件。 |
| send / fail / flash | Watch 一键 | 形成进步和成就记录。 |
| rest 时间 | Watch 自动计时 | 判断节奏和疲劳。 |
| 心率 | Watch | 参考强度和恢复，不做绝对判断。 |
| 主观疲劳 RPE | 训练后 1-10 分 | 弥补传感器不足。 |
| 恐惧/信心 | 训练后简短标记 | 抱石心理因素很重要。 |
| 失败原因 | 训练后选项 | 例如力量、脚法、读线、恐惧、耐力。 |
| 线路属性 | 颜色、难度、墙面、倾角 | 帮助理解自己偏好和弱项。 |
| 下次目标 | iPhone 复盘 | 把 recap 变成 next-session recall。 |

## 14. 实地调研清单

如果要继续做更深的市场调研，可以每去一个岩馆按这张表记录：

| 维度 | 观察问题 |
| --- | --- |
| 选址 | 商场/办公区/社区/体育中心？客流从哪里来？ |
| 价格 | 单次、次卡、月卡、年卡、体验课、私教、青少年课分别多少？ |
| 用户 | 成人多还是孩子多？男女比例？新手多还是老手多？ |
| 线路 | 多久换线？难度分布如何？新手线是否友好？ |
| 教练 | 是否主动教学？是否转化课程？安全讲解是否充分？ |
| 社群 | 是否有群、活动、比赛、女性夜、新手局？ |
| 私域 | 是否加企业微信？是否推课程/活动/续费？ |
| 内容 | 小红书/抖音/公众号是否活跃？内容是什么风格？ |
| 零售 | 是否卖鞋、镁粉、服装、咖啡？转化自然吗？ |
| 安全 | 垫子、巡场、落地教学、自动保护器、儿童管理如何？ |
| 体验 | 第一次来是否无压力？训练后是否想再来？ |
| 产品机会 | 哪些信息用户现场想记但没有地方记？ |

## 15. 最终判断

抱石在北京和上海的发展，不是偶然的潮流，而是几个长期趋势叠加的结果：

1. 城市年轻人需要比健身房更有趣、比酒局更健康、比跑步更社交的运动；
2. 家庭需要更有挑战性、可展示进步、可进入赛事路径的青少儿体育项目；
3. 商场需要能制造停留、围观和内容传播的新业态；
4. 户外品牌需要真实线下场景承载装备、社群和文化；
5. 岩馆需要从卖门票转向卖成长路径和社群关系；
6. 用户需要从“我运动了多久”升级为“我今天解决了什么问题、下次要怎么进步”。

所以，抱石最有价值的深层需求不是“爬墙”，而是：

> 在一个安全、可社交、可重复挑战的环境里，持续获得可见进步、身体掌控感和社群身份。

商业上，真正可持续的岩馆不是只会拉新，也不是只会装修，而是能同时做好：

1. 安全和合规；
2. 定线内容生产；
3. 教练和课程体系；
4. 青少儿长期路径；
5. 成人社群留存；
6. 私域和内容运营；
7. 赛事/活动/品牌合作；
8. 数据化复盘和会员生命周期管理。

对 `watchapp/climb` 项目来说，这份行业调研进一步支持一个判断：

> 先做“个人抱石训练记忆系统”，比先做“岩馆路线库”或“攀岩社交平台”更现实。用户个人的 attempt、rest、send/fail、project 和下次训练记忆，是离 Apple Watch 最近、离真实训练痛点也最近的入口。
