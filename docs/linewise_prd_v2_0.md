## 1. 一句话与方向变化

**一句话**：拍一面墙，扫一下，整面墙的岩点被抠出来；点一个，同色的整条线亮起来；按自己的身材把动作摆一遍、播一遍；爬完记住掉在哪、下次试什么。

**为什么从 v1.1 改**

- v1.1 以记忆闭环为核心，并冻结功能等现场验证；建线靠手动点圆圈。
- 2026-10 的原型证明端侧读线可行（见 `docs/linewise_hold_segmentation_proposal_2026-09-13.md`）：
  - SAM 2.1 Tiny 在真实墙照上 24 个点里 21 个贴合真实轮廓；
  - 手指点偏后形状仍稳定，重合度 0.76，圆圈只有 0.60；
  - 彩色线"点一个、找全部同色"基本可用；
  - 白、黑、灰色岩点是短板。
- 产品所有者判断：读线和模拟是吸引人、留下来的理由，记忆闭环是它们的落点。
- 竞品已有火柴人 Beta、3D 墙、视频 AI，"有火柴人"本身不构成差异。差异在三点：
  1. 拍完几秒内在手机上完成整面墙读线，可改，不上传；
  2. 按自己的身材模拟，并和自己的掉落记录连在一起；
  3. 整条流程的手感。
- **功能冻结解除。** 现场验证从"开工门槛"改为每个 Demo 都要带的并行动作（§10）。

## 2. 用户与时刻

用户不变：有热情的新手（1–12 个月）和有习惯的老手（1 年以上）。不服务教练、岩馆、绳索、户外。

| 时刻 | 在做什么 | 手的状态 | 能接受的操作 |
| --- | --- | --- | --- |
| 墙下读线（新） | 拍墙、看线、想动作 | 干净或有镁粉 | 拍 1 + 点 1–3 下出线；愿意花 1–3 分钟摆动作 |
| 进馆前 / 热身 | 决定先磕哪条 | 干净 | 看，滑几下 |
| 攀爬中 | 掉下来、休息 | 镁粉、手机在包里 | 0–1 下 |
| 爬完 / 回家 | 复盘、回放、分享 | 干净 | 每条线 4–8 下 |

## 3. 产品原则

1. **聚光灯是唯一视觉母题。** 暗下去的墙，加上亮着的岩点真实轮廓。轮廓取代圆圈；抠不出来的点仍画圆圈。
2. **一切按线组织。** 不做按天的视图。
3. **系统给建议，可一下改掉，不打分。** 识别出的点、颜色组、起步和结束、动作草稿都是建议。模拟遵守身体尺寸和关节范围，但不评分，也不判定"能不能爬"。
4. **只用端侧轻量模型。** 单个模型 ≤ 100 MB，第一次读线时下载，iOS 17 可用。不上传照片，没有账号。大于 100 MB 的模型（如 SAM 3）不进本版。
5. **动效解释因果。**
   - 动画从手指出发，比如点一下后的涟漪。
   - 等待由动画承接：扫描光带的位置就是识别进度。
   - 每个动画都在说明一次状态变化，不做装饰性的循环动画。
   - 尊重系统"减弱动态效果"。
6. **直接操作。** 在图上点、拖、长按；不做按钮面板去控制手脚；竖屏不左右分栏。
7. **操作预算是硬指标。** 建一条线 ≤ 10 秒（从拍完照到完成，彩色线）；记一次 ≤ 4 下；攀爬中可以一下都不按。
8. **Demo 驱动。** 每个 Demo 都在真实岩馆里用过一次，再决定下一步。

## 5. 场景与流程

### 5.1 读线（新建线的主流程）

1. **拍照**：也可以选相册，或选已有的墙。
2. **扫描**：
   - 照片压暗，一道光带从下往上扫过。
   - 光带的位置跟随识别进度，最快 1.2 秒扫完。
   - 光带扫过的地方，浮现小白点，每个白点代表"这里有一个岩点"。
3. **抠形**：扫描结束，小白点渐隐，同时在原位浮现岩点真实轮廓的淡描边，从下往上依次出现。此时整面墙的岩点都只有淡描边，墙仍是暗的。屏幕提示"点一个你要爬的点"。
4. **选线**：
   - 点任意一个岩点：它立刻亮起。
   - 同色岩点以它为中心，按距离由近到远依次亮起（涟漪），编号随之弹出。
   - 不同色的描边淡出。
   - 顶部出现颜色胶囊，例如"黄 · 9 个"。左右滑胶囊可以换成墙上的其他颜色组。
5. **校正**：
   - 点亮着的点：熄灭，移出这条线。
   - 点暗着的轮廓：点亮，加入这条线。
   - 点没有轮廓的地方：在点击处单独抠形；抠不出来就画圆圈。
   - 长按一个点：设为起步、设为结束、删除。
6. **起步和结束**：
   - 默认最低的点是起步，最高的点是结束。
   - 起步的第二圈描边沿轮廓"画"出来；结束点的小旗从上方落下。
   - 长按可以改，起步最多 2 个。
7. **完成**：光带再扫一遍作为确认，然后进入线路页。

**分支**

- 白、黑、灰这类低饱和颜色：点了之后只亮被点的那一个，胶囊上显示"找相似"，由用户主动展开整组。原型里这类颜色会误亮告示牌、衣服、白面体积点，所以不默认展开。
- 模型还没下载或正在下载：用手动点圆圈建线，和 v1.1 一样；同时后台下载。下载完成后，线路页提示"可以把圆圈换成轮廓"，一下替换。
- 整面墙一个岩点都没识别出来：回到手动点圆圈。
- 同一面墙再建一条线：直接复用这面墙已有的识别结果，跳过扫描，进入第 3 步。
- 无照片线：不变。

### 5.2 模拟

- **体型**：
  - 第一次进模拟时，用一屏滑尺问身高，臂展默认等于身高；腿长比例可选。
  - 不问体重：体重在画面上看不出区别，只会多一个隐私问题。
  - 设置里可以改。
- **起始姿态**：双手在起步点上，双脚在地面（已有）。
- **拖动**：
  - 拖手或脚的末端，肢体跟着手指走。
  - 拖动中，够得着的岩点轻微发亮，够不着的稍微变暗。这只是提示，不阻止放置。
- **松手**：
  - 吸附到最近的岩点上，落在轮廓里的手脚落点，伴随弹簧动画和一下触感。
  - 身体用反向运动学跟随：关节角度合理，手抬高时髋部贴墙。
  - 如果超出臂展：肢体拉直，缺口画成虚线并标出差多少厘米。只是显示，不判定。
- **步骤条**：每放一步，底部胶片条追加一格。
  - 点任意一格：身体以动画过渡到那一步的姿态，不瞬移。
  - 停在中间某格再拖：后面的格子变半透明，预示将被替换（已有）。
- **计划和实际**两份，标出差异（已有）。

### 5.3 回放与导出

- **播放**：
  - 步骤之间平滑过渡，每步约 0.6 秒。
  - 移动的肢体走弧线；躯干稍晚跟上；画面自动取景跟随。
  - 可以拖动进度条；每一步轻触一下。
- **掉落定格**：这条线记过"掉在第几步"时，回放停在那一步，珊瑚红脉冲三下，浮出"下次试什么"。
- **导出**：
  - GIF：540 宽，约 12 帧/秒，≤ 6 MB。
  - 视频：1080×1920 MP4。
  - 都带聚光灯和右下角品牌字，在手机上生成，不上传。
- 原来的分享图保留。

## 6. 交互与动效

具体的时长、曲线和触感见 UI 规范 §4.8–§4.14。这里只定规则。

| 时刻 | 动效 | 它在说明什么 |
| --- | --- | --- |
| 扫描 | 光带从下往上，扫过处浮现小白点 | 正在识别，进度到哪了 |
| 抠形 | 小白点渐隐，原位淡入轮廓描边 | 识别完成，这些是岩点 |
| 选线 | 从手指处向外的涟漪，同色点依次亮起，编号弹出 | 你点的这个，和它同色的是一条线 |
| 校正 | 点亮或熄灭 0.2 秒，配撤销条 | 这个点加入或移出了这条线 |
| 起步和结束 | 第二圈描边沿轮廓画出；小旗落下并回弹 | 从这里开始，到这里结束 |
| 拖手脚 | 肢体跟手；够得着的点微亮；松手后弹簧吸附 | 这一步放到了哪里 |
| 新增一步 | 新的一格从右侧滑入胶片条 | 记下了一步 |
| 回放 | 弧线插值，躯干稍晚，镜头跟随 | 这条线是怎么爬上去的 |
| 掉落定格 | 珊瑚红脉冲，浮出"下次试什么" | 上次就是在这里掉的 |

**规则**

- 第一帧立即响应：点亮、吸附、熄灭都在点击的同一帧有反馈；模型的结果到了再过渡过去。
- 等待超过 0.3 秒的地方，都必须有动画承接，不出现空白的转圈。
- 一次只有一个主角在动。
- 开启"减弱动态效果"时：涟漪变为一起淡入；弧线插值变为直切；光带改为进度条。

## 7. 端侧技术方案

**模型**

- Apple 官方转换的 SAM 2.1 Tiny（Core ML，FLOAT16，3 个包共 79.7 MB，Apache 2.0）。
- 第一次读线时下载，下载期间可以手动点圆圈建线。

**流水线**

1. **整图编码**：拍照后对整张图编码一次。Mac 上 0.14 秒，iPhone 待测。
2. **全墙预分割**：
   - 在墙面区域铺一张自适应网格，从下往上逐行做点提示，扫描光带跟着这个进度走。
   - 落在已经找到的岩点里的网格点直接跳过。
   - 每个点取得分高、且面积和形状像岩点的那个轮廓，重叠的去掉。
3. **每个岩点记录**：轮廓多边形、中心、手脚落点、颜色签名（中位 Lab）、面积。
4. **颜色分组**：以用户点的那个岩点为种子，按色差把同色岩点归为一组（亮度权重减半，用来容忍阴影）。低饱和种子不自动展开（§5.1）。
5. **单点补抠**：在点击处做点提示；只要面积不超过原圆圈 4 倍的最小候选；没有合格的就画圆圈。

**真机门槛**（iPhone 13 及以上）

| 项 | 门槛 |
| --- | --- |
| 整图编码 | ≤ 1.5 秒 |
| 全墙预分割 | ≤ 6 秒；超时就先展示已完成的部分，其余边算边出 |
| 单点补抠 | ≤ 150 毫秒 |
| 内存峰值 | ≤ 400 MB |

全墙预分割达不到门槛时，降级为只做单点抠形。

**存储与隐私**

- 轮廓存成归一化多边形，每个岩点 ≤ 64 个点，不存遮罩图片。
- 全部在手机上完成。

## 8. 数据模型变化

| 对象 | 变化 |
| --- | --- |
| Wall | 新增 `detectedHolds`（id、多边形、中心、手脚落点、颜色 Lab、面积、来源：模型 / 手动）和 `segmentationVersion`（模型版本，换模型时可以重算） |
| Hold（线上的点） | 新增 `polygon?`（没有就画圆圈）、`detectedHoldID?`、`anchor`（手脚落点，默认是轮廓内离中心最近的点） |
| Line | 新增 `colorGroup?`（Lab 值和显示名） |
| BodyProfile | 身高、臂展、腿长比例（可选）；取代 v1.1 的"身高、臂展"两项 |
| Sequence | 不变；回放插值不存储 |

迁移：SwiftData 先把现有模型定为 `VersionedSchema` V1，再迁移到 V2。旧线没有多边形，继续画圆圈。

## 10. 节奏

| Demo | 内容 | 要回答的问题 | 退出标准 |
| --- | --- | --- | --- |
| **A · 抠轮廓** | FR-70–73；SwiftData V1 迁移基线；真机测速 | 轮廓在真机上够快吗？比圆圈好看多少？ | 真机达到 §7 的编码和单点门槛；3 面真实墙主观"好看"≥ 8/10；建线不比圆圈慢 |
| **B · 读线** | FR-74–77 | 点一个能不能把一条彩色线基本找全？ | 彩色线一次点击后，正确的点 ≥ 85%、误亮 ≤ 15%；校正次数中位 ≤ 2；建线中位 ≤ 10 秒 |
| **C · 模拟与回放** | FR-80–86 | 会不会真的去摆动作、播放、分享？ | 2 次馆访中 ≥ 3 条线做了模拟，≥ 1 次导出或分享；回放 60 fps |
| **D · 动作草稿** | FR-90–91 | 草稿能省事吗？ | 草稿里被保留的步数 ≥ 50% |

- 每个 Demo 至少带 1 次真实馆访，馆访后填 v1.1 §10.4 的反馈模板。
- v1.1 Demo 1 的记忆闭环现场验证和 Demo A 一起做。
- 任何一个 Demo 没过退出标准，对应功能就降级，不继续打磨。

## 11. 指标

只在本机计算，不上传。

| 指标 | 采集方式 | 目标 |
| --- | --- | --- |
| 建线时长 | 拍完照到完成 | 彩色线中位 ≤ 10 秒 |
| 抠形贴合率 | 最终保留的轮廓点 / 全部点 | ≥ 80% |
| 校正次数 | 一条线建线中的点亮和熄灭次数 | 中位 ≤ 2 |
| 模拟使用率 | 有计划顺序的线 / 尝试 ≥ 3 次的线 | ≥ 30% |
| 导出率 | 导出 GIF、视频或分享图的线 / 有顺序的线 | 观察 |
| 记忆闭环 | 提醒回答率、复盘完成率、重访率 | 沿用 v1.1 §10.5 |

## 12. 风险

| 风险 | 对策 |
| --- | --- |
| 真机太慢 | Demo A 先测速；预分割边算边出；不达标就降级为单点抠形 |
| 白、黑、灰色误识别 | 低饱和颜色不自动展开；用户一下可改 |
| 80 MB 下载劝退 | 第一次读线时才下载，并说明大小；下载期间手动建线可用 |
| 一次推三个大模块，范围膨胀 | 严格按 Demo A → D 推进，每个 Demo 只做退出标准要求的东西 |
| 竞品已有火柴人 | 差异落在端侧秒级读线、自己的身材、和掉落记录连通、手感 |
| 模拟被当成"教你怎么爬"的权威 | 标为"示意"或"草稿"；不评分；超出臂展只显示差多少 |
| 照片里有其他人 | 识别只在本机进行；分享前提示（已有） |

## 13. 不做与红线

**本版不做**

- 视频录制或分析；从视频里识别人的姿态；动作评分
- 3D 网格人（用火柴人或剪影）
- 大于 100 MB 的模型（包括 SAM 3）、云端 AI、账号
- 体重
- 社区、公开 Beta、岩馆数据库、教练后台、订阅
- Apple Watch、iPad 和横屏布局、搜索

**红线**（沿用 v1.1）

- 不请求定位，不请求相册全量访问
- 不做医疗、安全、伤病相关表述
- 不从照片或体型推断用户的能力
- 没有用户明确操作，不改写用户的记录
