# LineWise 接手验收 · 2026-09-13

来源：Cursor 会话 `16779d61-fdb1-4daf-8d6d-973172586687`；接手分支 `feat/ios-app-v1`，原基线 `a0f939f`。原会话最后要求停止后台工作并记录 handoff，本次从遗留的未提交 UI 打磨开始集成。

## 当前范围

产品以 [PRD v1.0](linewise_prd_v1_0.md) 和 [UI 规范](linewise_ui_spec_v1.md) 为准：iPhone、本地优先、按线组织，照片点亮 → 记录掉在哪 → 提醒与复盘 → 手动计划／实际顺序 → 分享。旧 `CONTEXT.md` 和 v0.1 的 GymVisit／Watch 叙述尚未同步，不能用它们覆盖 v1.0 已确定的产品形态。

本次收尾已有打磨，修复回归并建立可重复验收；搜索、识别、iCloud 和 Watch 等后续功能不在本次集成范围。

## 修复

- 首次重跑 151 项测试发现 2 个失败用例、3 个断言失败。首页现在先按最近攀爬记录排序，再放未记录的新线；缓存包含创建时间，并对完全相同的时间使用稳定排序。
- 拖动岩点改变上下顺序时，自动起步不再被旧的自动结束点卡住；用户手动指定的结束点仍保留。
- 分享重新包含实际动作顺序和体型，快照与编辑器共用姿态求解；超过 8 步时保留首尾、原步号；预览可关闭“附上实际顺序”，导出缓存随选择失效。
- 无照片记录的新 `fallText` 和旧备注前缀统一只读解析。历史不会把有掉落位置的记录显示成“没掉”；分享及“问题变了”的提醒也保留文字掉落位置，撤销可恢复旧提醒。
- 减弱动态效果时，筛选胶囊和复制顺序后的撤销不再进行位移插值。
- 顺序拖动的点位遮罩与目标强调回到共享 `SpotlightImage`，上层只画肢体把手。
- 修复相邻照片预加载的 MainActor 警告，清除 XcodeGen 配置中重复的相册写入用途字段。

## 验证

- Xcode 26.6 / iOS Simulator 26.5 / iPhone 17。
- 单元及集成测试：156 项通过，包含排序、手动端点保护、无照片跨视图展示与提醒撤销、实际顺序分享姿态及关闭／恢复快照后的位图一致性。
- Debug 测试构建及 Release 模拟器构建通过。AppIntents 的“无框架依赖，跳过元数据提取”提示不影响构建。
- 真实墙照片：首页和线路页自动取景、记录表单与键盘避让已截图检查；实际点击验证 `+1`、撤销、记录保存和提醒回写。
- 原生 XCUITest：2 条通过。系统触摸拖动手部后步骤由 5 增至 6，撤销恢复 5；无照片建线 → 填写掉落位置 → 保存 → 重开，字段保留。测试使用内存数据库及独立偏好域，不读写正常用户记录。
- 原先的桌面模拟器控制未稳定触发拖动；原生 XCTest 触摸路径连续两次通过，未确认产品手势存在回归。UI 测试读取 DEBUG 专用的画布坐标后发送系统拖动事件，不直接调用手势处理函数。
- 真实照片分享图已渲染并检查，输出 1080×1920，实际顺序快照带、步号和动作说明完整。预览开关已显示；开关导致的渲染变化及恢复由位图回归测试验证，未对系统分享面板中的第三方目的地执行发送。
- 最终结果：`/tmp/linewise-codex-final.xcresult`（156 + 2 全绿）、`/tmp/linewise-codex-release-final.log`（Release 构建通过）。

## 对旧交接清单的更正

以下项目接手时已存在，不能继续算“未实现”：零点时禁用完成、点亮首次提示、相机权限拒绝后的去设置／不拍照入口、相邻卡片预加载、小字页码、头图副标题去重、记录键盘避让、顺序地面随最低岩点变化。

`Session.fallText` 在原基线中就已存在；本轮主要是把编辑及展示路径接完整，不是本次才修改了 SwiftData 模型。

“MVP / M1 / M2 全部功能齐全”表述不准确：FR-49 搜索、上了后提示复制计划为实际等仍未实现。功能代码存在也不等于已完成真机或真实馆访验证。

## 后续优先级

1. 建线精修：拖动放大镜、工具条撤销、已有墙缩略图取景、认旧线与新点的视觉区分。用真实照片实测建线耗时。
2. 复盘闭环：上了且没掉时提示复制计划为实际；FR-49 搜索。
3. 设置与可访问性：长按步进、非默认体型的恢复入口、导出进度、诊断中位数与复制、大字号及 VoiceOver 回归、浅色墙下姿态对比度。
4. 发布验证：真机相机、OCR、中文语音、ZIP 导出、分享性能；建立 SwiftData V1 迁移基线；正式图标与 TestFlight。
5. M3：颜色识别建议、相似线、跨线总结、提示库，随后再评估 iCloud 与 Watch。

既有打磨包含自动回放与馆访快照回退，而 PRD v1.0 曾排除自动连播和时间线海报。本次保留已存在的交互，不据此宣布新增需求已经获验收；下一次产品梳理需明确统一这两处契约。

## Review

Standards 轴原先发现的减弱动态与共享绘制边界问题已修复，复查没有发现新的可确认回归。按钮样式合并与掉落统计逻辑去重属于后续整理项。

Spec 轴发现的实际顺序分享回退、无照片历史展示、无照片提醒替换已修复，复查未发现新的集成错误。分享开关的缓存失效经静态复查；实际预览和位图开关回归已检查，第三方分享目的地仍属于真机验收范围。
