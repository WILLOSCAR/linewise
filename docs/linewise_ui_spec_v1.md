# 线感 · UI/UX 规范 v1

日期：2026-09-13
状态：Active，配合 `docs/linewise_prd_v2_0.md` §6 使用；实现以本文为准。2026-10-03 起新增 §4.8–§4.14（读线、模拟、回放的动效）
适用：iOS App（SwiftUI），`app/LineWise/`

---

## 0. 一句话

**把墙关灯，只留你的线。** 整个 App 的视觉与交互都从"聚光灯"这一个隐喻长出来：暗、少、亮点集中、光会动。

参考（取其气质，不抄形式）：Three.js 官网示例的"暗场 + 发光体 + 缓慢的光运动"；Halide 的手势优先与克制的 UI；Apple 相机/照片的缩放与点选手感；Strava 的分享卡；Things 的安静空态；Instagram Stories 的整页横滑。

## 1. 视觉语言

### 1.1 色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| Ink 背景 | `#0D0D12` | 所有页面底色 |
| Panel | `#1C1C24` / `#29292F` | 区块、浮层 |
| Accent 聚光黄 | `#FFD12E` | 唯一强调色：亮点描边、提醒、主按钮、当前步 |
| Coral 掉落红 | `#FF7361` | 只用于掉落点 |
| 文字 | 白 / 白 55% | 主 / 辅 |

规则：一屏里黄只做一件事（要么是亮点，要么是主按钮，两者共存时按钮降为白底/材质）。除 Coral 与状态图标外不出现第三种彩色。

### 1.2 光

- **亮点 = 光源**。每个点：原图亮度的圆孔 + 双层描边（外层 `accent 45%`、4pt 软；内层 `accent`、1.5pt 锐）+ 半径 2.2× 的径向光晕（`accent 30% → 0`）。
- **蒙版**：`#05050A` 66% + 四角 35% 的暗角（vignette），让视线自然落到亮点。
- **扫描光带**：一条 56pt 高的柔光带从下往上扫。读线时它跟随识别进度（§4.8），完成建线时再扫一次作为确认（1.2s，`easeInOut`），经过的点先放大 22% 并闪一下（白 60% 环 0.25s）再回落，编号随之弹出。
- **轮廓**：岩点用真实轮廓开孔；描边沿轮廓走（内层 `accent` 1.5pt，外层 `accent 45%` 4pt 软）；光晕按轮廓外扩。起步点在轮廓外再加一圈（间距 5pt）；结束点的小旗插在轮廓顶部中点。抠不出来的点仍是圆圈。
- **"表演"时刻只有三个**：读线（扫描 → 抠形 → 涟漪）、回放、建线完成的确认扫描。其他地方只用短的状态过渡。
- **火柴人**：白 2pt 圆头线 + 关节点；左手脚白、右手脚黄，便于一眼分左右。

### 1.3 字

- 标题 `.title2.bold`，正文 `.body`，辅助 `.footnote` + 55% 白。
- 数字一律 `design: .rounded` + `monospacedDigit`。
- 点的编号用带圈数字 ①…㊿，全 App 统一（卡片、历史、提醒、顺序、分享图）。

### 1.4 形

- 圆角：卡片 18–28pt `continuous`；胶囊用于所有可选项与浮层按钮。
- 浮层按钮统一 `ultraThinMaterial` 圆形/胶囊，白字。
- 不用分割线；用间距和 Panel 分组。

## 2. 动效语言

| 场景 | 曲线 | 时长 |
| --- | --- | --- |
| 状态切换、胶囊选中 | `.snappy` | 0.2s |
| 卡片/面板出现 | `.spring(duration: 0.35, bounce: 0.15)` | — |
| 火柴人肢体吸附 | `.spring(duration: 0.35)` 插值姿态 | — |
| 扫描揭示 | `easeInOut` | 1.2s（读线时跟随进度，最短 1.2s） |
| 涟漪点亮 | `.spring(duration: 0.3, bounce: 0.35)` | 按距离错开，每 100pt 35ms |
| 回放每步 | `easeInOut` | 0.6s |
| 撤销条 | `.move(edge: .bottom) + .opacity` | 0.25s |

规则：
- 一切动效都是**状态变化的解释**，不做装饰性循环动画。
- 触感与动效同步：点亮/吸附 `light`，+1 `medium`，完成/上了 `success`，删除 `warning`。
- `accessibilityReduceMotion` 开启时：扫描直接到位，插值改为直切。

## 3. 交互原则（降低理解与操作成本）

1. **一屏一件事**：首页只做"看"，建线只做"点亮"，记录只做"四下"。次要操作收进"更多"。
2. **直接操作优先于表单**：掉在哪 = 点图上的点；起步/结束 = 长按点；顺序 = 拖手脚。能在图上做的，不做成列表。
3. **默认值替代询问**：起步默认最低、结束默认最高、日期默认今天、墙区默认上次、难度 OCR 预填。用户只改不对的。
4. **随处可撤销，几乎不确认**：所有破坏性操作走 5 秒撤销条；只有"删除岩馆 / 删除全部"需要确认。
5. **手势要可预期**：横滑只切线；捏合只缩放；点只切换；长按只出菜单。同一手势在不同屏意义一致。
6. **反馈即时**：点亮、+1、吸附都必须在同一帧响应，异步只用于读盘与 OCR。
7. **文案短、口语化、无术语**：用"掉在哪 / 为什么 / 下次试什么"，不用"失败点 / 原因分类 / 提醒对象"。
8. **空态 = 一句话 + 一个动作**。

## 4. 逐屏规范升级点

### 4.1 首页（横滑）
- 整页横滑，`scrollTargetBehavior(.paging)`；相邻卡片缩放 0.94、透明 65%（`scrollTransition`），当前卡片满幅。
- 卡内聚光灯图自动取景到这条线（4.7），随滑动做 15% 视差（`visualEffect` 取滚动位置）。
- 顶部只有岩馆胶囊、筛选胶囊、齿轮；底部只有页码与"+"。
- 卡片文字三行以内；提醒行带黄色灯泡（已验证换为印章）。有提醒时第二行只写"第 N 次来"，掉哪·原因交给提醒和图上的珊瑚红点，不重复。

### 4.2 建线
- 来源选择：四张大卡（拍照 / 相册 / 已有的墙 / 不拍照），带一句说明。
- 点亮屏：图占满，底部一条毛玻璃工具条。点一下即亮（同帧），编号重排有 0.2s 位移动画。长按点出上下文菜单。
- 完成 → 扫描 → 自动进线路页；轻触可跳过。

### 4.3 线路页
- 上半聚光灯图（约 48% 屏高，自动取景到这条线，标题与状态叠在图底部的渐变上），下半 Panel 列表：提醒 / 记录 / 教练 / 顺序 / 历史 / 更多。
- 图跟着列表滚动做拉伸（下拉放大、上滑收缩淡出），点图进全屏查看。
- `+1` 是唯一的大黄按钮；"上了"是开关；"记这一次"是次级链接样式。
- 历史筛选影响图上的掉落点；图上掉落点透明度随时间由浅到深。

### 4.4 记这一次
- 上半图可点选点（同帧高亮）；下半表单按价值排序，全部可跳：（有待验证提醒时）上次这句有用吗 → 上了吗 → 为什么掉 → 下次试什么 → 试了几次 → 日期（PRD §6.4）。验证块：问句"上次这句有用吗？"，下面一行灰字引用被验证的那句提醒（不用黄，保存按钮已占了黄），再下面是和线路页相同的四个小胶囊，可再点取消。保存后 1.5s 展示拼好的提醒。

### 4.5 顺序（火柴人）
- 图占满上方（自动取景到这条线的包围盒，见 4.7），步骤条在底部横向排列（胶片条，约 96pt 高），不做左右分栏——竖屏下分栏会让画布小到没法拖。
- 拖动中目标点放大并加白环；松手吸附有弹性；胶片条自动滚到当前步；点某格回退，后续格半透明预示将被替换。
- 顶部只保留：关闭、标题（计划 / 实际）、撤销；"复制为实际"收进更多菜单或作为空态动作。

### 4.7 自动取景（所有出现聚光灯图的地方）
- 用 `SpotlightGeometry.focusRect(for: holds, padding:minSize:)` 把线的包围盒放大到视图里，而不是把整张照片 fit 进去。真实墙照通常有一半是天花板和垫子，整图 fit 会让线只占屏幕 1/3。
- 首页卡片 padding 0.35 / minSize 0.45；线路页 hero 与顺序编辑器 padding 0.30 / minSize 0.5；全屏查看器默认整图 fit，双击切到取景。
- 图比视图大的方向不露底板，图比视图小的方向居中（`SpotlightGeometry` 已处理）。

### 4.8 读线 · 扫描与抠形（PRD §5.1 第 2–3 步）
- 拍完照：照片先以 0.25s 压暗到蒙版强度，同时出现光带（在底部）。
- 光带位置 = 预分割进度（网格从下往上逐行处理）。识别比 1.2s 快时，光带按 1.2s 匀速走完；识别慢时，光带停在当前进度并轻微呼吸（亮度 ±10%，1s 周期），这是全 App 唯一允许的循环动画，因为它在表达"还在算"。
- 小白点：每找到一个岩点，在它的中心出现一个 6pt 白点（白 70%）。出现时缩放 0 → 1，`.spring(duration: 0.3, bounce: 0.5)`，配 `selection` 触感，每 80ms 最多一下。
- 抠形：光带到顶后 0.1s，小白点按从下往上依次（每个错开 10ms）缩到 0；同时同位置的轮廓描边淡入（白 45%，1pt，0.35s `easeOut`）。全部完成后提示文字从底部淡入："点一个你要爬的点"。

### 4.9 读线 · 点一个亮一串（第 4 步）
- 被点的岩点在同一帧亮起（亮区 + 光晕），并从手指处放出一圈涟漪（白 60% 细环，0.4s 扩到 120pt 并淡出），配 `medium` 触感。
- 同色岩点按到手指的距离依次亮起：每 100pt 错开 35ms；每个点亮区 0 → 1（0.25s `easeOut`），缩放 0.92 → 1.04 → 1（`.spring(duration: 0.3, bounce: 0.35)`）；编号在它亮起 0.1s 后弹出。
- 触感：同色点亮起时最多再给 5 下 `light`，均匀分布，不跟每个点一下。
- 不在组里的轮廓描边在 0.4s 内淡到 0。
- 颜色胶囊从顶部滑入（0.3s spring）："黄 · 9 个"。左右滑胶囊：当前组 0.2s 淡出，新组从离屏幕中心最近的那个点开始涟漪。
- 低饱和颜色：只亮被点的那个；胶囊上显示"找相似"，点了才展开涟漪。

### 4.10 读线 · 校正与起步结束（第 5–6 步）
- 点亮着的点：0.2s 熄灭到描边状态，底部出撤销条。点描边：亮起并放一圈小涟漪（60pt）。点空白处：同一帧先出圆圈，轮廓算好后 0.25s 由圆变形到轮廓（交叉淡化 + 缩放对齐）。
- 起步：组亮完 0.3s 后，起步点外圈沿轮廓"画"出来（描边裁剪 0 → 1，0.5s `easeInOut`）。结束：小旗从轮廓顶部上方 20pt 落下，`.spring(duration: 0.45, bounce: 0.4)`。
- 长按（0.35s）出菜单：设为起步 / 设为结束 / 移出这条线。

### 4.11 模拟 · 拖手脚（PRD §5.2）
- 拖动的是肢体末端（手、脚的圆点，热区 44pt）；末端 1:1 跟手，其余关节用反向运动学实时求解，躯干比末端晚约 60ms 跟上（看起来有重量）。
- 拖动中：臂展内的岩点亮区提高到 30%；超出的降到 15%。离手指最近、可吸附的点加白环并放大 8%。
- 松手：末端沿最短路径吸附到落点，`.spring(duration: 0.35, bounce: 0.3)`，配 `light` 触感；超出臂展时肢体拉直，缺口画成 1.5pt 虚线并标"差 12cm"（白 70%，小字）。
- 新的一步：胶片条右端滑入一格（0.3s spring），胶片条自动滚到它。
- 点胶片条某一格：身体用 0.4s 过渡到那一步的姿态（不是瞬移）；被替换预示的后续格子变为 40% 透明。

### 4.12 回放（PRD §5.3）
- 每步 0.6s `easeInOut`。移动的肢体末端走弧线：控制点在起止连线中点向墙外（远离躯干）偏移 15% 的距离；躯干晚 80ms 跟随；镜头取景框在相邻两步的包围盒之间插值。
- 进度条在胶片条上方，可拖动；拖动时直接按插值求姿态（不播放）。每到一步给一下 `light` 触感。
- 掉落定格：到达"掉在第几步"时停下，落点珊瑚红脉冲 3 下（每下 0.4s，环扩到 2 倍半径并淡出），"下次试什么"卡片从底部淡入；点任意处继续或关闭。
- 减弱动态效果：每步直切，不插值；定格脉冲改为静态珊瑚红环。

### 4.13 导出
- 分享按钮上出现环形进度；完成后弹系统分享面板。GIF 540 宽、12 帧/秒；视频 1080×1920、30 帧/秒；画面同回放，最后停 1.5s 在完整线路上；右下角小字品牌。

### 4.14 反直觉清单（不要做）
- 不用按钮面板去移动手脚；不做"选择左手 → 选择目标点"的两步操作。
- 竖屏不左右分栏；步骤列表永远在底部。
- 不用转圈的加载指示；等待都由光带或进度承接。
- 不在识别结果上弹确认对话框；错了就点掉，并且可以撤销。
- 不让动画阻止操作：任何动画进行中，点击都立即生效，并打断动画。

## 5. 实现约定（SwiftUI）

- 颜色常量在 `Components/Theme.swift`；不要在视图里写字面色值。
- 聚光灯所有绘制在 `Components/SpotlightImage.swift` 的 Canvas 内完成，其他视图不要自己画点。
- 浮层按钮/胶囊/大按钮/区块统一用 `Chip` / `BigButtonStyle` / `Panel`。
- 动效曲线从上表取值；触感通过 `Haptics`。
- 任何新页面先写 `#Preview`，再接线。
