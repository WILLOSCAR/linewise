## Demo A · 抠轮廓：迁移基线、Tiny 单点分割与真机验收

GitHub：[12](https://github.com/WILLOSCAR/linewise/issues/12)。

需求：FR-70–73；§7、§8、§10。

- [x] 将当前 SwiftData 模型固定为 VersionedSchema V1，验证旧数据；加入 V2 可选轮廓/落点迁移，旧线仍画圆圈。
- [x] 模型按需下载，展示大小、进度、重试；未就绪或失败时手动建线可用。
- [x] Tiny 单点抠形源码、面积筛选与圆圈回退；异步结果绑定照片/模型版本及 Hold 身份，失效结果不可覆盖新输入。共用核心已在 Mac 实跑；iOS Simulator 遮罩解码兼容性失败，真机待测。
- [x] 建线、首页、线路页、记录、顺序及分享使用一致轮廓渲染；单点圆圈到轮廓淡入，识别等待展示实际阶段／点数。
- [ ] iPhone 13 及以上：编码 ≤ 1.5 s、单点 ≤ 150 ms、峰值内存 ≤ 400 MB，记录首次编译与实际测量方法。
- [ ] 3 面真实墙主观“好看”≥ 8/10，建线不比圆圈慢；至少一次真实馆访，并完成 v1.1 Demo 1 记忆闭环现场验证。

## Demo B · 读线：整墙、颜色组、校正与同墙复用

GitHub：[13](https://github.com/WILLOSCAR/linewise/issues/13)。

需求：FR-74–77；§5.1、§7、§10。

- [ ] 通过 Demo A 退出标准后启动；先用真机结果确定网格密度与速度取舍。
- [ ] 全墙后台候选提取、去重、进度与分批显示；≤ 6 s，否则边算边出或降级为单点抠形。
- [ ] 点一个展开同色线、颜色胶囊切换；白/黑/灰不自动展开。
- [ ] 点亮、熄灭、补抠、长按起步/结束均可撤销；同墙第二条线复用已有扫描。
- [ ] 真实馆访：彩色线正确点 ≥ 85%、误亮 ≤ 15%、校正中位 ≤ 2、建线中位 ≤ 10 s；先约定人工标注与分母，不能用候选数替代正确率。

## Demo C · 模拟与回放：体型、可达提示、掉落定格及导出

GitHub：[14](https://github.com/WILLOSCAR/linewise/issues/14)。

需求：FR-80–86；§5.2–5.3、§6、§10。

- [ ] 通过 Demo B 退出标准后启动。
- [ ] 先补齐真实长度尺度来源与误差的产品契约，再实现厘米差距；网页缩放比例不能当作实测长度。
- [ ] 身高/臂展/可选腿长比例、关节约束、可达提示与吸附；提示不阻止放置，不评分。
- [ ] 点格过渡、弧线回放、镜头跟随、可拖进度与触感；掉落定格连接“下次试什么”。
- [ ] 本地 GIF（540 宽、约 12 fps、≤ 6 MB）与 1080×1920 MP4 导出。
- [ ] 两次真实馆访中至少 3 条线做模拟、至少一次导出或分享；真机回放 60 fps。
